# ITS Education

ITS Education is a children's technology and engineering education institute focused on programming, electronics, robotics, and engineering through practical projects.

## Core progression
**Discover → Build → Program → Understand → Design → Create**

Learning cycle:
**Learn → Experiment → Build → Break → Debug → Understand → Improve → Create**

## Target students
| Level | Age | Stage |
|---|---:|---|
| Explorer | 6–8 | Discovery |
| Maker | 8–11 | Practical building |
| Junior Engineer | 11–14 | Engineering foundations |
| Young Engineer | 14–17 | Advanced engineering |

## Core areas
Programming, electronics, robotics, engineering, embedded systems, mechanical design, and product development.

## Current development stage
Educational architecture, Level 1 course architecture, project system, teacher guide, student materials, assessment system, laboratory BOM framework, pilot operations, and financial model framework have been developed. The next business task is to populate the financial model with real purchasing and operating data.
