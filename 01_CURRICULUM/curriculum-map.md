# Curriculum Map

| Level | Age | Objective |
|---|---:|---|
| Explorer | 6–8 | I can make something happen. |
| Maker | 8–11 | I understand how the things I build work. |
| Junior Engineer | 11–14 | I can design a system. |
| Young Engineer | 14–17 | I can design and build a real product. |

## Programming
**Scratch → Python → C/C++ → Arduino/ESP32 → Embedded programming**

## Electronics
**Electricity → Circuits → Components → Sensors/Actuators → Microcontrollers → Power electronics → PCB design**

## Robotics
**Mechanisms → Motors/Servos → Sensors → Control → Autonomous systems → Integrated robots**

## Engineering
**Build → Measure → Debug → Prototype → Design → Document → Improve → Product**

## Level map

### Explorer
Basic electricity, simple circuits, Scratch, simple mechanisms.

### Maker
Electronics, Arduino, sensors, motors, measurement, robotics foundations.

### Junior Engineer
Electronics, C/C++, Python, ESP32, robotics, CAD, IoT, communication, power and motor control.

### Young Engineer
Embedded systems, PCB design, advanced programming, control systems, robotics, product development, power electronics, system integration.
