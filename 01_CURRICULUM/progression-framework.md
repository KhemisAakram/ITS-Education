# Progression Framework

Progression is based on demonstrated capability rather than class count alone.

## Explorer → Maker
Identify components; build simple circuits; explain LEDs; use switches; follow diagrams; work safely with low-voltage supplies; explain simple projects.

## Maker → Junior Engineer
Use a multimeter; understand voltage/current/resistance; build sensor circuits; program Arduino; control motors and servos; troubleshoot; document; explain system behavior.

## Junior Engineer → Young Engineer
Design systems; use C/C++ and Python; work with ESP32 and communication protocols; integrate sensors and actuators; use CAD; prototype; debug hardware/software interaction; document engineering decisions.

## Young Engineer completion
Define requirements; develop system architecture; select components; design electronics; program embedded systems; prototype mechanical elements; test; debug; revise from evidence; document; present and defend design decisions.

## Independence scale
**Guided → Developing → Capable → Independent Maker**
