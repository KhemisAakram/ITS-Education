## Specification standard

A production project specification should contain:

1. Project information
2. Purpose and problem
3. Learning objectives
4. Skills developed
5. Required concepts
6. Components and materials
7. Tools
8. Safety
9. System architecture
10. Student design
11. Build procedure
12. Testing
13. Debugging
14. Improvement challenge
15. Extension challenges
16. Student explanation
17. Teacher guide
18. Assessment
19. Required evidence
20. Project quality check

## Documentation status

The repository currently contains project identity/reconstruction records for the 24 projects. These records preserve the confirmed project names and sequence without pretending that unavailable original procedures or component specifications were recovered.

The next production step is to develop and validate each project specification against the corresponding lesson plan, equipment system, safety requirements, and assessment system.

## Separation from finances

The ITS Education financial documents are planning artifacts for the future institute/business model. They are not a record of the owner's personal finances, debts, or actual available capital. Any future financial figures must be explicitly identified as assumptions, estimates, or verified institute data.
