# Electronics & Programming — Level 1

**Age:** 8–11  
**Duration:** 12 weeks  
**Sessions:** 24  
**Frequency:** 2 sessions/week  
**Session length:** 90 minutes

## Course objective
Move students from simple electronic experiments toward programmable sensor, motor, and robot systems, ending with an independent invention.

## Session progression
1. Introduction to Technology & Electricity — LED circuit
2. LEDs & Polarity — LED Indicator
3. Buttons and Switches — Push-Button LED
4. Mini Traffic Light
5. Understanding Resistance — LED Control Experiment
6. Potentiometers — Brightness Controller
7. Buzzers & Sound — Electronic Doorbell
8. Electronic Alarm — Mini Electronic Security Alarm
9. What Is a Sensor? — Sensor Experiment
10. Light Sensor & Automatic Night Light
11. Temperature Sensor — Simple Temperature Monitor
12. Mini Sensor Challenge
13. Understanding Motors — Mini Motor System
14. Motor Control — Controlled Motor System
15. Servo Motors — Servo-Controlled Mechanism
16. Build a Mechanical System — Automatic Gate
17. Introduction to Microcontrollers — Programmable LED
18. Programming Inputs — Button-Controlled System
19. Loops & Repetition — Programmable Light System
20. Sensor + Program — Smart Sensor Device
21. Build a Simple Robot — Simple Two-Wheel Robot
22. Robot Sensors — Sensor-Controlled Robot
23. Final Engineering Project — Student Invention
24. Final Demonstration & Course Assessment — Maker Demonstration Day

## Teaching model
20% theory, 30% guided experimentation, 50% project work.

## Completion
Students demonstrate practical competence, debugging, explanation, documentation, and increasing independence.
