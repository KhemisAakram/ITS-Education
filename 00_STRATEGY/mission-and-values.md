# Mission & Values

## Mission
Provide children with structured, practical, progressive education in programming, electronics, robotics, and engineering through experimentation and projects.

## Values
- **Curiosity** — ask why, how, and what happens if.
- **Building** — Build → Test → Improve.
- **Understanding** — explain the principles behind projects.
- **Experimentation** — test ideas safely.
- **Debugging** — observe, hypothesize, test, correct, retest.
- **Independence** — Instructor → Guide → Mentor.
- **Creativity** — modify, redesign, and extend.
- **Safety** — treat safety as an engineering skill.
- **Collaboration** — communicate, divide tasks, document, test, present.
- **Real-world engineering** — requirements, design, prototyping, testing, debugging, documentation, revision, presentation.

## Principle
**Understand → Build → Test → Debug → Improve → Create**
