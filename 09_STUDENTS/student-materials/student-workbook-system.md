# Student Workbook System

## Purpose
The workbook documents student thinking, not just final answers.

## Engineering notebook
Each student maintains a project record.

## Standard project sheet
- Project title
- Today's question
- What I know
- Prediction
- Components
- System design
- Circuit sketch
- Build
- Experiment
- Test
- Debugging
- One-change rule
- Improvement
- Explain the system
- Reflection
- Self-assessment
- Teacher observation
- Portfolio evidence

## Session page
Record the concept, experiment, observations, result, problem, test, and lesson learned.

## Programming worksheet
Problem, inputs, outputs, algorithm, code, test cases, errors, fixes, improvement.

## Sensor worksheet
Sensor, physical quantity, expected response, measurement, threshold, test, observation.

## Robotics worksheet
Mechanical design, motors, sensors, control logic, tests, failures, improvements.

## Final project workbook
Problem definition, requirements, ideas, selected design, system architecture, build log, tests, debugging, revisions, final explanation, reflection.

## Portfolio
Keep selected projects, diagrams, code, measurements, photographs where appropriate, explanations, and reflections.

## Design principle
Early worksheets are highly guided. Guidance decreases as student independence increases.
